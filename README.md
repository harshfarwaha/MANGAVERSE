# MangaVerse

A mobile-first manga discovery experience with a cinematic Shōnen × Seinen visual identity.

## Catalogue architecture

MangaVerse is designed to browse **10,000+ manga metadata entries** without shipping thousands of records in the frontend bundle. Catalogue data is fetched on demand from a legitimate metadata API, paginated, cached in memory, and rendered only when needed.

Actual manga chapters/pages should only be hosted or displayed when their distribution is authorized, public-domain, or properly licensed.

## Current build

- Mobile-first dark manga UI
- Shōnen / Seinen discovery sections
- 10K+ catalogue-ready architecture
- Search with pagination
- Genre filtering
- Trending / popular / new sections
- Lazy-loaded cover images
- Manga detail modal/page structure
- Responsive navigation
- Manga-inspired animations
